# 任务

## 背景：一个真实的信息丢失

写操作任务（`--tools implement`）每一单都会开一个隔离的 git worktree，分支名形如 `devloop/<任务名>-<时间戳>`。跑完后 `devloop/cli.py::cmd_dispatch` 会把这个分支名 **只打印到 stdout**：

```
分支 devloop/xxx-20260726-163208（保留供你审查；丢弃：git worktree remove --force ...）
```

而 `devloop/telemetry.py::record` 写进台账的那一行里，有 `report`（回执 JSON 的路径），**没有 branch**。

后果：终端一滚走，你就再也无法把台账里某一行失败记录对应回它的现场分支。worktree 从不自动删除，`git worktree list` 会攒一堆分支，而哪条分支对应哪次失败，只能靠时间戳猜。「现场保留供你审查」这句承诺目前是半兑现的——现场在，索引没了。

本单要把这个字段从产生处贯通到消费处，并补上测试。

## 要改的四处

**1 · `devloop/telemetry.py::record` —— 写入侧**

- 新增一个仅限关键字参数 `branch: str | None = None`，排在现有的 `gate_ok` / `gate_detail` 之后。
- 在写出的行里新增键 `"branch"`，值就是该参数；位置放在现有的 `"report"` 之后。
- 只读任务不传该参数，此时这一键必须**存在且为 null**（不是缺键）。理由与本项目既有约定一致：台账每行的键集合稳定，缺键和空值是两个不同的意思。

**2 · `devloop/cli.py::cmd_dispatch` —— 产生侧接线**

- 调用 `telemetry.record(...)` 时把分支名传进去：有 worktree 时传 `wt.branch`，没有（只读任务）时传 `None`。
- 不要改动 `record` 调用现有的其它实参，也不要改动那句打印分支的 print。

**3 · `devloop/telemetry.py::summarize` —— 读取侧**

`summarize` 是 `devloop stats` 打印的内容。在它**现有全部输出行之后**追加一段：

- 只挑 `ok` 为假**且** `branch` 非空的行（即：未过关的写任务）。
- 把这些分支名逐个列进返回的字符串里（分支名必须原样出现，前后加什么措辞由你定）。
- 没有这类行时，一个字都不要追加。
- ⛔ **已过关（`ok` 为真）的写任务分支不得出现在输出里。** 只列失败的，因为那才是需要人去现场看的；全列出来会让这段随派单次数无限膨胀，变成噪声。

**4 · 向后兼容（这条最容易漏）**

台账是**追加写的 JSONL 历史文件**，本次改动之前写下的行**没有 `branch` 这个键**。`summarize` 读到那些旧行时必须照常工作，不许抛 `KeyError`。注意 `summarize` 里现有代码风格并不统一——有的地方用 `.get()`，有的地方直接下标。你新加的读取逻辑必须用容错的取法。

## 测试：位置有硬性规定，先读完再动手

`tests/` 是判定标准，**任何改动、包括在里面新建文件，都会被闸直接判失败**（闸用 `git status --porcelain -- 'tests/'` 检查，未跟踪的新文件同样会被抓到）。

因此本单为新测试指定一个新位置：

- 新建目录 `tests_worker/`，在其中新建文件 `tests_worker/test_telemetry_branch.py`（文件名照抄，不要自拟——basename 与 `tests/` 下已有文件重名会导致 pytest 收集报错）。
- **必须同时**把 `tests_worker` 登记进 `pyproject.toml` 的 `[tool.pytest.ini_options]` 的 `testpaths`，改成 `testpaths = ["tests", "tests_worker"]`。不登记的话，闸跑的 `python -m pytest -q` 根本不会收集你的测试，等于白写——这正是本项目反复交学费的那类「实现了 ≠ 接上了」。
- 至少写 3 个测试，合起来覆盖下列**全部 4 条行为**（可以合并，但一条都不能缺）：
  1. 写任务：`record(..., branch="devloop/xxx")` 后，台账行的 `branch` 等于该值
  2. 只读任务：不传 `branch` 时，台账行有 `branch` 键且为 `None`
  3. `summarize` 列出未过关写任务的分支，**且不列出**已过关写任务的分支
  4. 手工造一行不含 `branch` 键的旧台账记录，`summarize` 不崩

改 `[tool.pytest.ini_options]` 是本单**明确许可**的；`pyproject.toml` 的 `[project]` 段（依赖与版本）仍然不许碰。
