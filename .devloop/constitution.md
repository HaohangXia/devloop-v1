# 宪法 · 什么必须停下来问人

> **本文件是给人读的权威表述。** 机械判据在 `constitution.toml`，两者靠条款 ID 对应。
>
> ⛔ **任何脚本不得解析本文件。** 理由不是洁癖：这个项目已经有过一次教训——
> `rules-digest.md` 里白纸黑字写着「`.devloop/` 任何文件禁改」，
> 而**真正执行它的是 `gates.sh` 里那段脚本**；散文改成什么都不影响执行。
> 宪法若只写成散文，就是第二个 rules-digest：**守卫的目标不存在**。
>
> 本文件的 SHA-256 登记在**项目外**的锚文件里。修改它必须重新锚定
> （`devloop constitution anchor`），那是一条需要人执行的命令。

每条标注 `[judge: …]`：

| 标注 | 含义 |
|---|---|
| `auto` | 有机械判据，脚本能判 |
| `partial` | 判得了一部分，**射程写在条款里** |
| `none` | ⛔ **判不了**，已在 `constitution.toml` 的 `[[unjudged]]` 里登记 |

⚠️ 判定结论**每次**都会带上「未覆盖 N 条：…」的尾巴。
「零命中」从来不等于「查过了没事」，它等于「**查过的那部分**没事」。

---

## A. 自指类（最高优先）

自主系统的经典逃逸路径：**改自己的规矩**。

### A-1 · 不得修改闸或宪法本身 `[judge: auto]`

`gates.sh`、`constitution.md`、`constitution.toml`。
**改自己的规矩 = 立即停机上报。**

判据：T0 登记 SHA-256（对账项目外的锚），T5 复验。
⚠️ 锚**绝不以现值为新基准**——能自愈的锚不是锚。

### A-2 · 不得修改 `~/.claude/` 配置或工具本体 `[judge: partial]`

⚠️ **射程不完全，这一点不许含糊**：判据只覆盖清单里列出的白名单路径。
工人有 Bash，工作目录只是起点不是牢笼，**写到白名单之外不可枚举、不可判定**。

这一条没有边界，只有覆盖率。真边界是文件系统受限的执行环境，当前不具备。

### A-3 · 不得调整自己的预算/重试/并发上限 `[judge: none · 目标不存在]`

⛔ **本条当前是空条款**：这三个上限还没有持久化状态，守卫无从下手。
**先有受保护的状态，才谈得上守卫。不要先写守卫。**

### A-4 · 不得修改项目 `.devloop/` 下的文件 `[judge: auto]`

白名单：`gates.sh`、`rules-digest.md`、`config.toml`、`constitution.*`。
⚠️ 排除运行产物（`reports/`、`jobs/`、`telemetry.jsonl`）——它们每单都变，
纳入进来守卫会天天红，而天天红的守卫等于没有守卫。

### A-5 · 不得产出绕闸的脚本 `[judge: none · 本质如此]`

⛔ 无自动判据：工人有 Read 权限，读闸是权限内的正常动作，
「读闸」与「意图绕闸」无法从字节区分。

本条靠**让绕闸无效**而非可检测：闸从仓库外的只读副本执行 + 派单前指纹校验。
⛔ **不得把「零命中」读成「没绕闸」。**

## B. 不可逆类

### B-1 · 删除文件或目录 `[judge: auto · 仅记账]`

⚠️ 判得了，但**只记账不上报**。理由：工人在一次性 worktree 里删东西
只损失它自己那一单，删掉关键文件测试必红、闸会裁决。
而**每次删除都上报会把宪法上报变成噪音，噪音会训练人去忽略上报**——那比不上报更糟。

### B-2 · `rebase` / `reset --hard` / `push --force` / 删分支 / 改历史 `[judge: auto]`

判据：T0 与 T5 的 ref 快照对账。已存在的 ref 变了或消失了 = 命中。
新增的 `devloop/*` 分支豁免（那是工具自己造的隔离分支）。

⚠️ 并发派单时本判据**射程收窄**（只比对 T0 时已存在的 ref），这一点写在结论里。

### B-3a · 不得修改依赖清单文件 `[judge: auto]`
### B-3b · 不得安装或升级依赖 `[judge: none · 够不着]`

清单文件判得了；安装本身落在仓库之外，只能靠隔离的执行环境 + 人。

### B-4 · 任何对外发送 `[judge: none · 够不着]`

提 PR、发消息、发邮件、调用外部写接口。

⛔ **事后完全零痕迹**：发出去的东西在 diff、台账、回执里都不留证据。
**唯一手段是事前不给能力**：

1. 硬拒 `--tools full` + **无人值守**（已实现，见 `[refuse]`）

   ⚠️ 2026-08-03 之前这里写的是「`--tools full` + `--detach`」，而判据也真的
   只挂在那个开关上——⛔ **自动驾驶那条路从头到尾没调用过这道硬拒**，
   计划里写 `tools = "full"` 就能让工人整夜握着 WebFetch。
   ⭐ 判据现在挂在「**这条路有没有人在看**」（`unattended`）上：
   `--detach` 是无人值守，自动驾驶**按定义**也是。
2. ⚠️ 工具白名单**不是边界**——`bash -c` 绕得过去。把它当边界就制造了「有守卫的错觉」
3. **无外网执行环境就绪之前，不得让工人在无人值守下跑 full 档**

## C. 决策类

### C-1a · 设计文档**路径**变更 `[judge: none · 本仓无目标]`

判据本身是机械可判的（一条 `[[protected_tree]] glob = "01_设计文档/**"` 即可），
⛔ **但本仓根本没有那个目录**——而宪法拒绝匹配 0 个文件的模式，
理由是「写错的模式会永远报『无命中』」。

⚠️ 2026-08-03 之前这里标着 `[judge: auto]`，而 toml 里保护它的那条是**注释掉的**：
一条自称有机械判据的条款，既没有判据、也没登记为判不了、也不出现在
「未覆盖 N 条」那句尾巴里。⭐ 它是靠**同族豁免**（`C-1a` 被归到 `C-1`、
借 `C-1b` 的名额）从覆盖率测试里溜过去的——三档相加 17，散文 18，而测试是绿的。

⭐ 接入了设计文档目录的项目，把那条 `[[protected_tree]]` 打开即可；
⛔ 在打开之前，标注必须是实话。

### C-1b · 设计**决策**变更 `[judge: none · 靠人采样]`

同一个阈值 0.3→0.5 可能是实现细节，也可能是设计决策——**判据在意图里，不在字节里**。

⛔ **特别禁止给它编启发式**（「改动超 N 行 = 设计变更」）：
那比没有判据更坏，因为它会产生一个**可信的绿**。

### C-2 · 基线变更 `[judge: auto]`

参考数据、哈希常量等。判据：base 锚定的漂移。

### C-3 · 任何 push、以及合并到集成分支之外的分支 `[judge: auto]`

判据（2026-08-03 起）：T5 比对**全部** ref 的集合差——
新增 `refs/remotes/*` 即命中；新增远端或改远端 URL 同样命中。

⚠️ 在此之前，这一条声称由一条**静态检查**（扫工具源码里有没有 `push`）挡着。
⛔ 那条检查的对象是**工具的代码**，而本条款的主语是**工人的动作**——
主语错了。实测：工人 `git push origin HEAD:refs/heads/x` 推送成功，宪法零命中。

### C-3b · 推到裸 URL `[judge: none]`

`git push <完整URL> HEAD:refs/heads/x` 不经过任何具名远端，
**本地零痕迹**：不建 `refs/remotes/*`、不改 `remote.*.url`、reflog 里也没有。

⛔ **判不了。** 与 B-4「对外发送」同族——真边界只有事前不给网络能力。
⚠️ 从 C-3 里拆出来单列，是因为「C-3 有人挡了」这句话对整条不成立；
不拆就等于**用挡住的那一半，把没挡住的那一半盖掉**。

### C-4 · 任何触及用户主线或集成分支的 `git commit` `[judge: auto]`

⚠️ **收窄射程**：本条**不含**工具自造的一次性隔离分支 `devloop/<任务>-<时间戳>`。
派单流程会在**跑完闸之后**把产出固化到该分支，主线一个字节不动。

**为什么必须收窄**：原条款按字面禁止一切自动提交，而不提交的代价是
**产出静默丢失**——曾有一单五闸全绿、答案卷全过的产出就是这么没的。
条款护的是用户的主线，不是防止工具给自己造的临时分支留存档。

⛔ **合回主线仍然要用户逐单批准，这一条没有松动。**

> 判据落在 `commit_result` 里：提交前断言 HEAD 就是本 worktree 的隔离分支。
> 这不是理论风险——工人在 worktree 里跑一句 `git symbolic-ref HEAD refs/heads/master`
> 就能让产出落到主线，而工具还会打印「产出已固化到隔离分支」。

### C-5 · 预算耗尽，或单任务重试 N 次仍失败 `[judge: partial]`

⚠️ 落地时**必须显式处理「算不出成本」**：价目表里没有该模型时成本是 `None`，
不处理的话「算不出」会被当成「花了 0 元」，**预算永远不会耗尽**。
判据 = 任何一行算不出成本即判停，并说清是哪个模型不在价目表里。

### C-6 · 阶段完成 → 上报验收结论请人放行 `[judge: none · 本来就是人]`

### C-7 · 例外层自认拿不准 `[judge: none · 靠人，软信号]`

⛔ 「自认拿不准」是**模型自述**，直接撞本项目的第一铁律。
保留它作为软信号（有用），但必须配硬对偶：
**例外层被触发次数 ≥ N 即停机上报**——那个是可判定的，就是数数。

⛔ **绝不能写「例外层没喊停 = 没问题」。**

## 信任爬梯（逐档解锁，跳档 = 违规）

| 档 | 形态 | 解锁条件 |
|---|---|---|
| 1 | 人在场，看一个工作包全自动跑完 | — |
| 2 | 人离场半天，自主跑完一个阶段，只在边界/例外找人 | 档 1 无宪法违规 + 成本在预算内 + **急停实测有效** + **至少触发过 1 次宪法上报并被正确处理** |
| 3 | 过夜 / 多阶段连跑 | 档 2 连续两个阶段无人工救火 |

> ⚠️ 档 2 的条件不是「零违规」——**若档 1 期间宪法从未被触发，「零违规」是无意义的**。
> 没被测过的机制不算工作，与「闸要红绿双测」同一条原则。
